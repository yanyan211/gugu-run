# 菇菇大逃亡

咪菇在哥特古堡里无尽奔跑的网页小游戏，可以换道、转弯、跳跃、滑铲，收集银币、解锁皮肤、升级道具，还有账号和排行榜。

## 怎么玩
- 左右滑：换跑道；到转角时往路的方向滑动转弯
- 上滑：跳过长桌；下滑：钻过吊灯和尖刺
- 逃亡过程中随机出现道具，捡到即刻开始生效：吸金磁铁、双倍金币、无敌护盾

## 文件
| 文件 | 内容 |
|---|---|
| index.html | 页面和界面 |
| game.js | 游戏程序（Three.js 打包） |
| models.js | 咪菇 3D 模型 |
| castle.js | 城堡场景模型 |

账号和排行榜接口在 https://api.cino1018.com/api/run/ ，需要服务器上的 gugu-run 服务在运行。
